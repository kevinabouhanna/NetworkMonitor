# Phase 4: Pictures, videos and docs

**Milestone:** Phase 4: Pictures, videos and docs · **Status:** Next

**Goal:** everything people see before installing (the website, the README, the docs) shows
the app as it is today, and the app links into its docs.

## The plans

- **Every picture and video shows the current app** (#499): the launch video and its poster,
  remade by hand from the redesign (#458), and the last false alarms and gaps in `site-check`
  (#526).
- **Each ⓘ links to its page in the docs** (#230): "Learn more" at the end of each ⓘ, opening
  the docs page and heading for that setting, with a test that fails when a heading moves. The
  docs pages are on the website since #334.
- **Short videos of features on their docs pages** (#539): Pause, the Connections map, a
  firewall rule and Enhanced ad blocking's switch, 10–20 seconds each. They take real work, so
  Kevin says when.
