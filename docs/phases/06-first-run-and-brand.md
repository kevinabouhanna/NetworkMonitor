# Phase 6: First run, name and logo

**Milestone:** Phase 6: First run, name and logo · **Status:** Later

**Goal:** a first-time user understands every permission the app asks for, and the app has a
name people remember and can search for, a logo that stands out, and a website at its own
address.

## The plans

- **Improve onboarding** (#522). NetworkMonitor touches about ten permissions or approvals,
  and a feature switched on without its permission often shows nothing. One notice in every
  feature that can't work, with the one button that fixes it, and clear states for refused
  and waiting. After the features of phases 2 and 3, since each adds a permission.
- **Branding** (#582), in order:
  1. a first check of what AI assistants say about the app today (#583);
  2. a distinctive name (#578), since "NetworkMonitor" is too generic to search for;
  3. a stronger logo, with the name (#579);
  4. a website at the app's own address (#580);
  5. a second check of search and AI answers, a few weeks after the launch (#581).

The name comes before the launch (phase 7): launching under the old name would waste the posts.
