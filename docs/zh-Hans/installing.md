# 安装、更新和卸载

[English](../installing.md) · 简体中文

NetworkMonitor 可在 macOS 13 或更高版本上运行，支持 Apple 芯片和 Intel 芯片的 Mac。它以一个通用磁盘映像 `NetworkMonitor.dmg` 提供，附在每个 [GitHub 发布版本](https://github.com/kevinabouhanna/NetworkMonitor/releases)中。

## 已签名并经过公证

NetworkMonitor 使用 Kevin Abou Hanna 的 Apple **Developer ID**（团队 `GRQKG7M8CL`）签名，并经过**公证**：Apple 已检查过它是否含有恶意软件，并签发了随应用一起提供的票据。因此 macOS 知道它的开发者是谁，打开它时不会显示警告。1.13 及更早版本没有经过签名和公证，需要你在“系统设置”中点按 **仍要打开** 来批准。

如果你不想直接信任一个二进制文件，全部代码都在这个仓库中，而且[自己构建](../development.md)（英文）只需要 Apple 免费的 Command Line Tools。

## 安装

1. [下载 NetworkMonitor.dmg](https://github.com/kevinabouhanna/NetworkMonitor/releases/latest/download/NetworkMonitor.dmg)，打开它，然后将 **NetworkMonitor** 拖到 **应用程序** 文件夹中。
2. 从“应用程序”文件夹中打开 NetworkMonitor。

菜单栏中会出现 ↓ ↑ 读数。NetworkMonitor 没有程序坞图标，也没有自己的主窗口；一切都从这个读数开始。它会把自己设为登录时启动，你可以在 **设置 › 通用** 中关闭。

第一次打开时，欢迎窗口会提供两个选项，都不是必需的（#134）：

- **查看你的应用访问了哪些网站**：一个内容过滤器，用于在[连接](connections.md#网站名称)中显示服务器的名称，并让阻止功能成为可能。
- **按名称识别你的 Wi-Fi 网络**：只有在获得定位服务权限后，macOS 才会提供网络名称，而它只用于这一个用途。没有这项权限时，网络会显示为类似 *Wi-Fi · 3f2a* 的名称。

这两项都不会再主动询问。如果你跳过了其中一项，在用到它的地方会有 **打开…** 按钮：网站名称在“设置 › 连接”中，Wi-Fi 名称在“设置 › 通用”中。

## 更新

从 1.15 开始，NetworkMonitor 使用 Sparkle 自行更新（#132）。它每天向 GitHub 询问一次是否有新版本（使用热点时不会询问），并提示你：显示新功能，准备好后点按 **安装更新** 即可。从它的菜单中选择 **检查更新…** 会立即检查，在“设置 › 关于”中可以关闭每日检查。只有当更新的磁盘映像使用应用内置的密钥签名时，才会安装它。

1.15 之前的版本，或者想手动更新时：

1. 下载新的 `NetworkMonitor.dmg`。
2. 将 NetworkMonitor 拖到“应用程序”文件夹中，然后选择 **替换**。
3. 打开它。

从 1.13 或更早版本更新时，macOS 会再询问一次定位服务权限：应用现在使用 Developer ID 签名，而不是它自己的证书，所以 macOS 这一次会把它当作新应用。

你的设置、总计和流量历史都保存在应用之外，不会受影响。

如果你使用[热点模式](hotspot-mode.md)，它的辅助程序会随新版本一起更新，不会询问任何问题。如果你之前使用的版本中辅助程序要求输入密码，NetworkMonitor 会提示一次新的辅助程序：在“系统设置”中打开它后，旧辅助程序的 sudoers 规则就会被移除。

如果从源代码检出构建，`make update` 会拉取代码、运行测试、重新构建并重新安装。测试会先运行，所以有问题的拉取不会替换掉正常工作的版本。

## 卸载

右键点按菜单栏读数，然后选择 **卸载 NetworkMonitor…**，或者打开 **设置 › 关于** 并点按 **卸载…**。它会依次：

1. 移除内容过滤器（如果你打开了网站名称）：它的设置会立即移除，扩展本身由 macOS 移除，可能要到下次重新启动时才完成；
2. 移除辅助程序（如果已安装），辅助程序会先恢复它更改过的内容（没有 Developer ID 的构建版本中的辅助程序会要求输入密码）。如果这一步失败或你取消了，其他内容都不会被改动；
3. 恢复热点模式在没有辅助程序的情况下更改过的设置；
4. 移除登录项、你的流量历史和你的设置；
5. 将应用移到废纸篓。

**直接把应用拖到废纸篓是不一样的。**辅助程序会在一小时内发现应用已经不在了，然后恢复它所做的更改（系统更新设置、受管理的策略、低数据模式），并移除自己。但那些不需要密码就能更改的更新设置会一直保持关闭，因为记录如何撤销这些更改的是应用本身，而它已经不在运行，没有东西能读取这些记录。如果你已经把它拖到了废纸篓，请把它拖回来，打开它，再从菜单中卸载。

如果从源代码检出构建，`Scripts/uninstall.sh` 会做同样的事。

## macOS 如何显示辅助程序

如果你打开热点模式，应用会注册一个小型辅助程序，macOS 会在 **系统设置 › 通用 › 登录项与扩展** 的 **允许在后台** 下、NetworkMonitor 名下列出它，等你打开（#131）。它每小时运行的自我修复任务也列在 NetworkMonitor 名下。它具体能做什么，请参阅[热点模式](hotspot-mode.md#辅助程序)。
