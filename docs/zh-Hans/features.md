# 功能

[English](../features.md) · 简体中文

NetworkMonitor 能做的一切，以及在哪里找到它们。

## 菜单栏读数

两行，始终可见：绿色的 <strong>↓ 下载</strong> 在上，浅灰色的 <strong>↑ 上传</strong> 在下，单位为 <strong>MB/s</strong> 或 <strong>Mbps</strong>（<strong>设置 › 通用 › 速度显示单位</strong>）。Mbps 与宽带套餐的标称速度一致；MB/s 与流量总计一致。数据量始终以 MB 和 GB 显示，与流量套餐的计算方式相同。你可以在 <strong>设置 › 通用 › 菜单栏颜色</strong> 中选择其他颜色。

读数<strong>宽度固定</strong>，所以数字变化时，菜单栏中它旁边的项目不会跳来跳去。它每秒最多更新两次，使用电池和低电量模式时更新得更少（请参阅[电池](accuracy-and-battery.md#电池)）。网速测试进行时，读数会以青色显示测试结果；如果你选的颜色接近青色，则改用另一组颜色，这样测试结果永远不会被误认为实时速度。

- <strong>点按</strong>它可打开弹出窗口。
- <strong>右键点按</strong>（或按住 Control 键点按）它，可使用 <strong>测试网速</strong>、上一次的结果、<strong>全部阻止</strong>（#198）、<strong>连接…</strong>（⌘K）、<strong>流量历史…</strong>（⌘Y）、<strong>设置…</strong>（⌘,）、<strong>检查更新…</strong>、<strong>卸载 NetworkMonitor…</strong> 和 <strong>退出</strong>。

## 弹出窗口

- <strong>总计</strong>：当前连接自你加入以来（或自午夜以来）用掉的流量，合计为一个数字。下面一行显示正在使用哪个连接，使用热点时以橙色显示。如果你加入了热点，但 Mac 正在使用另一个连接，它会提示你，ⓘ 中会说明如何切换。
- <strong>产生这些流量的应用</strong>，从多到少排列，每个应用都有一个表示占比的条形。应用之间互相超过时，列表会实时重新排序；圆点表示此刻正在传输数据的应用。
- <strong>辅助进程归入所属应用</strong>：Chrome 的十几个辅助进程合并为一行 *Google Chrome*。
- <strong>命令显示在启动它们的应用下方。</strong>点按 iTerm2 或 VS Code，可以看到它启动的 `node`、`git` 或 `curl`，每个都有自己的数字。超过四个时会合并为 *其他（n）*。
- <strong>系统</strong>：macOS 自己的守护进程合并为底部的一行。好奇的话可以展开它。
- <strong>仍下载的更新</strong>：使用热点且打开了[热点模式](hotspot-mode.md)时，总计下方会有一行提示是否仍有更新被下载。
- <strong>按应用统计已暂停</strong>：如果无法启动 macOS 的 `nettop`，会有一行灰色文字提示，同时 NetworkMonitor 会继续重试。总计不受影响，照常统计。
- <strong>顶部按钮</strong>：仪表图标运行[网速测试](speed-test.md)，地球图标打开[连接](connections.md)，图表图标打开[流量历史](usage-history.md)，齿轮图标打开“设置”。

列表可显示八行，外加第九行的一部分，所以被截断的那一行说明下面还有更多。按 Esc 或点按其他地方即可关闭。

## 每个连接的总计

加入另一个 Wi-Fi 网络或热点后，总计会从零开始，所以你看到的就是*这个*连接用掉的流量。在新的地方打开热点，你就能确切知道每个应用在上面用了多少。

- <strong>断线后重新连接</strong>到同一个网络，会接着之前的数字继续统计。
- <strong>午夜时也会重置</strong>，即使你一直没有离开这个连接。
- <strong>重新启动后也会保留</strong>，在同一网络上重新打开应用会继续统计。
- <strong>立即重置</strong>（设置 › 通用）会让当前网络的总计重新开始。
- <strong>统计开始于</strong>（设置 › 通用）显示当前总计是从什么时候开始的。

不同网络通过路由器的硬件地址来区分，这不需要任何权限；网络则以它的 Wi-Fi 网络名称命名。只有在获得定位服务权限后，macOS 才会提供这个名称，应用会询问一次；如果你拒绝，网络会显示为类似 *Wi-Fi · 3f2a* 的名称。

之前的网络和日期的总计会保存到[流量历史](usage-history.md)中。

## 只统计互联网流量

投屏到 Apple TV、用时间机器备份到 NAS、从你自己的服务器播放 Plex：这些流量会经过你的 Wi-Fi，但不消耗互联网流量，所以永远不会被计入。只和你自己的网络通信的应用根本不会出现。请参阅[准确性](accuracy-and-battery.md#统计的是互联网流量不是你自己的网络)。

## 流量历史

按小时记录，可按应用和网络细分，保留多久由你决定。按日、周、月或年回顾；把每次访问某个网络看作一个连接时段；把所有内容缩小到一个应用、一个网络，或一次查看所有热点；导出为 CSV。请参阅[流量历史](usage-history.md)。

## 连接

你的应用把数据发送给了哪些公司、来自哪些应用、在哪些国家或地区、发往哪些服务器：可以按公司、应用或国家或地区分组，点按以缩小范围，进行搜索，在时间线上逐小时查看，还可以在世界地图上以颜色深浅显示，地图会在你的应用此刻连接的地方闪动。所有内容都不会在线查询。你可以阻止某个公司、应用、国家或地区、网站或服务器，也可以让它在应用第一次连接时询问你；一个开关即可在所有应用中阻止广告、跟踪器和恶意软件。请参阅[连接](connections.md)。

## 网速测试

点按一下，就会用 macOS 内置的工具重新测试一次：先测下载，再测上传，然后是延迟、抖动和负载下的延迟，单位为 Mbps 或 MB/s。如果有其他应用在争用线路，结果中会指出它。使用热点时，它会先询问你。请参阅[网速测试](speed-test.md)。

## 热点模式

一个开关就能在你使用移动热点时阻止应用更新，让连接进入低数据模式，并告诉你哪些应用无法阻止。请参阅[热点模式](hotspot-mode.md)。

## 设置

一个窗口，每个方面一个面板。窗口的标题和大小会跟随面板变化，最高可达屏幕高度，超出时面板内容改为滚动。它会在你上次使用的面板上重新打开。每一行的含义在它旁边的 ⓘ 中说明，指针移到该行上时就会出现（#185、#189）。

| 面板 | 内容 |
|---|---|
| <strong>通用</strong> | 语言：与 Mac 相同，或为应用单独选择 · 登录时启动 · 速度显示单位：MB/s 或 Mbps · Wi-Fi 名称（打开之前显示） · 菜单栏颜色：下载、上传、网速测试的颜色、使用默认颜色 · 弹出窗口中的累计值：统计开始于、采样、立即重置 |
| <strong>网速测试</strong> | 直接在这里测试 · 在弹出窗口中显示测试的样式：卡片或紧凑 |
| <strong>历史记录</strong> | [流量历史](usage-history.md) |
| <strong>连接</strong> | 功能说明，以及 打开“连接”… · 网站名称（关闭时显示 打开…） · 允许应用连接、你设置的每条规则、导出… 和 导入… · 广告和跟踪器：阻止广告和跟踪器、每个列表、今天已阻止、每周更新列表 · 打开时显示：列表、两者或地图 · 名称的来源，以及 每月更新 |
| <strong>热点</strong> | 停止热点下的应用更新 · 它对你当前连接的判断 · 使用热点时暂停：每个应用都有自己的开关，ⓘ 中说明如何暂停 · 不能暂停：每一项的原因在 ⓘ 中说明 · 低数据模式 · 仍下载的更新 |
| <strong>关于</strong> | 版本 · 网站、发行说明和源代码 · 自动检查更新、立即检查 · 卸载… |

“设置”打开时，NetworkMonitor 会有程序坞图标和菜单，所以 ⌘W、⌘, 和 ⌘Y 都能使用，⌘-Tab 也能找到它。关闭“设置”后，它又会回到只在菜单栏中运行的状态。

如果“设置”在另一个应用后面打开着，点按菜单栏项目只会显示弹出窗口，“设置”仍留在后面。用 ⌘-Tab 或程序坞图标可以单独显示“设置”。

## 不打扰你

- 没有程序坞图标，不出现在应用切换器中，没有需要管理的窗口。只在菜单栏中。
- <strong>默认在登录时启动</strong>，只设置一次。在“设置 › 通用”中关闭后，它就会保持关闭。
- <strong>退出后就保持退出。</strong>退出只会在本次登录期间结束它，不会关闭“登录时启动”；而关闭“登录时启动”也不会退出正在运行的应用。
- 支持自动隐藏菜单栏：菜单栏隐藏时弹出窗口仍保持打开，“设置”仍保持在最前面。
