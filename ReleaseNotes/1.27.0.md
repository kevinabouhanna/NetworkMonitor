- **NetworkMonitor in Chinese.** Every window, menu and setting, and everything VoiceOver reads, is now in Simplified Chinese too. A Mac set to Chinese opens it in Chinese; on any Mac, choose a language in Settings › General › Language (#429, #433).
- **NetworkMonitor 现已支持简体中文。** 所有窗口、菜单、设置以及 VoiceOver 朗读的内容都已翻译。系统语言为中文的 Mac 会自动以中文打开；你也可以在“设置 › 通用 › 语言”中选择语言（#429、#433）。
- **The docs in Chinese.** The README, the user guides and the wiki have a Chinese copy, linked from each English page (#430).
