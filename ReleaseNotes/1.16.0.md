- **Android hotspots are recognised.** A phone sharing its connection says so, and NetworkMonitor now listens, whatever address the phone hands out. A Samsung hotspot used to show as plain Wi-Fi (#109).
- **Settle it yourself when it guesses wrong.** Settings › Hotspot › **This network**: choose *Is a hotspot* or *Isn't a hotspot*, and it's remembered for that network (#109).
- **"Got through" shows the data an update used** while it downloaded, not the size it takes on disk, which overstated Slack's by more than double (#95).
- **What's new now shows in the update window** itself, rather than a web page (#152).
