- **Your hotspot, by name.** The menu bar window now says *Using hotspot · Kevin's iPhone*, and *Not using Kevin's iPhone* when you've joined a hotspot but the Mac is on another connection. Usage History names it too (#369).
- **Lines that fit.** The menu bar window's status lines no longer wrap or get cut off: *Not using …* and *… ads blocked today* each fit on one line (#369, #390).
- **Claude Code goes by its name.** It used to show up as its version number, like *2.1.319*, in Connections and in Ads and Trackers. It's now *Claude Code*, past days included (#385).
- **What a blocked count means.** An ⓘ beside the blocked total says it counts every try, so an app that keeps retrying a blocked site counts each attempt (#388).
