问题所在

你的 Mac 在背着你用流量。

应用会随时自行更新、同步和下载。在家用宽带上，你根本不会察觉。但在手机热点上，每一兆流量都要花钱，而 macOS 不会持续记录是哪个应用用掉的。

135 MB

制作这个页面时就碰上了一次。GoogleUpdater 在大约两分钟内从 13.9 MB 涨到了 135 MB，全在后台，自行其是。

在家里的 Wi‑Fi 上，这无伤大雅。换成热点，你的套餐在你察觉之前就少了 135 MB。

为什么很难察觉。

01

更新程序按自己的时间表运行。

Chrome、VS Code、Microsoft AutoUpdate、基于 Sparkle 的应用，以及 macOS 本身，都会在它们认为合适的时候获取新版本。没有任何东西会告诉你。

02

一个应用，藏在十几个名称背后。

浏览器会运行一大群辅助进程。终端会启动 git、ssh 和各种命令行工具。在原始的进程列表中，一个应用的流量分散在一堆你从没听说过的名称下。

03

“活动监视器”用的是另一套时钟。

它统计的是每个进程启动以来的字节数，而进程往往是几天前就启动了。它无法告诉你当前所在的网络用了多少。

04

本地流量看起来和互联网流量一样。

隔空播放到 Apple TV、用时间机器备份到 NAS、从你自己的服务器播放 Plex。这些都经过你的 Wi‑Fi，却都不会占用你的流量套餐。

05

热点按 GB 计费。

共享网络按流量计费。如果你要等运营商发来提醒才知道，流量早就用掉了。

06

流量监控工具什么都看得见。

任何监视你网络连接的东西，都有条件把它们报告出去。它应该什么都不索取，什么都不发送，并让你读到每一行代码。

解决方案

隆重介绍 NetworkMonitor。

一款小巧的菜单栏应用：实时显示网速，准确告诉你哪些应用在当前网络下消耗了多少流量、它们在和谁通信；只要你愿意，还能在你使用热点时阻止它们更新。它常驻菜单栏，想看细节时再打开一个窗口，也不需要账户。

热点模式

热点打开。
更新关闭。

只需一个设置。当你加入移动热点时，NetworkMonitor 会关闭应用的自动更新，你离开时再重新打开。应用照常工作。Chrome 照样浏览，Slack 照样收发消息，VS Code 照样编辑。只是在你按 GB 付费时，它们不会下载自己的新版本。

一加入热点就能认出来。

iPhone 个人热点和 Android 共享网络，无论通过 Wi‑Fi 还是 USB，无论来自你的手机还是别人的手机。你设为低数据模式的任何网络也算在内。“网络”页面始终会告诉你它对当前连接的判断；判断错了时，在那里或弹出窗口中打开这是热点即可更正。

这些需要应用自带的一个小型辅助程序：你只需在“系统设置”中打开一次，之后它会随应用一起更新。它只做五件事：暂停、恢复、打开和关闭低数据模式，以及报告状态。它会修改的设置都内置在它里面，它只响应 NetworkMonitor，也无法被要求更改任何其他内容。

连它从没见过的应用也能管住。

应用是根据它们的更新方式找到的，而不是靠一份名单，所以一个它从没见过的 Electron 应用也会被阻止，即使它正开着。同一个开关还会让热点进入低数据模式，这样 iCloud、照片以及所有遵循低数据模式的应用和服务都会减少后台数据传输，无论你装了什么。“网络”页面会列出每个它无法暂停的应用及原因；如果有更新还是在热点上溜了过去，弹出窗口会告诉你是哪个应用、用了多少。已暂停的应用如果更新了，也会标明这一点；每次溜过去的更新都会保留在“流量历史”中，并记在发生时的那次连接下。打开网站名称后，任何应用的更新程序也会在网络层面被阻止，无论它属于哪个应用。

查看“网络”页面

先改应用自己的设置。对于几乎所有应用，它修改的都是应用自己的“自动检查更新”设置，所以手动“检查更新…”仍然有效：它阻止的是无人值守的下载，而不是你。Canva、Figma 和 Chrome 是例外：有辅助程序时，在你离开热点之前，它们的更新服务器都无法访问。更新文件夹被锁定的 Electron 应用也是如此；打开网站名称后，任何应用独立的更新程序也是如此。

安全更新也会暂停。没有可靠的方法能区分安全补丁和功能更新，假装能区分只会更糟。离开热点或关闭该设置，一切都会恢复。

一切都会复原。点按“设置”中的“卸载 NetworkMonitor…”，或者右键点按菜单栏项目并选择“卸载 NetworkMonitor…”。它会把每项设置恢复成它当初看到的样子，然后移除辅助程序，并将应用移到废纸篓。

连接

你的应用在和谁通信。
尽在地图上。

每个应用都会把数据发往某处。“连接”会显示每个应用访问了哪些公司、国家或地区以及服务器，可以用列表、世界地图或两者同时查看，范围可以是今天，也可以是任意一天、一周、一个月或一年。按下 ⌘K，或点按弹出窗口中的连接。

按公司、应用或国家或地区查看。

展开一家公司，就能看到访问过它的应用、它的服务器从哪些国家或地区应答，以及服务器本身。改为按应用分组，可以看到一个应用在和哪些对象通信；也可以按国家或地区分组。时间线能把范围缩小到一个小时，地图会在你的应用此刻正在访问的国家或地区上闪动。

网站名称，经你同意。

单看服务器，它只是一个地址，云上的一切都会显示为托管于 Amazon。允许 macOS 中专为这类应用设计的那部分功能后，Slack 会显示为 slack.com，Chrome 的服务器也会显示名称。NetworkMonitor 首次打开时会提供这个选项，它是可选的，打开后无需任何管理。

阻止你选择的。

右键点按一家公司、一个应用、国家或地区，或者一台服务器：阻止、在热点上阻止、在“你所在的网络”上阻止，或始终允许。有名称的服务器按名称管理，也可以按整个网站管理，如 *.doubleclick.net。范围最小的规则优先，所以阻止 Meta 的同时允许 WhatsApp，结果会如你所愿。针对应用的规则跟随它的签名，因此任何顶替它的程序都不会继承这条规则。它的设置中会列出每条规则，还能导出给另一台 Mac 使用；显示：已阻止会列出被阻止的内容。

或者让它来问你。

选择询问我后，应用第一次访问某家公司时，会弹出一个小面板并写明网站：Figma 想要连接到 api.segment.io。你可以针对这个网站或整家公司作答，允许一次、直到应用退出，或者始终允许。30 秒内没有回应，就会放行。也可以选择仅允许已授权的连接。本地网络、域名查询和时间同步永远不会被阻止，macOS 自己的连接也从不询问。

一个开关，全部停下。

菜单栏右键菜单中的全部阻止，会阻止所有应用的连接，直到你把它关掉为止。在热点上开始一个大下载时，或者任何时候觉得不对劲，都可以用它。域名查询和你自己的网络仍能正常工作，读数会变成红色，所以不会因为疏忽而一直开着。

一个开关就能在每个应用中拦截它们，而且无论是否打开，它们使用的服务器都会在这里标出。

广告拦截

广告和跟踪器。
在每个应用中消失。

一个开关，就能拦截约 77,000 个广告和跟踪服务器，以及约 1,900 个正在传播恶意软件的服务器，范围是你 Mac 上的每个应用，而不只是浏览器。

每个应用，包括 Chrome。

浏览器扩展只能看到浏览器。它通过 macOS 中专门用于过滤连接的那部分功能工作，因此能拦下所有应用发往这些服务器的内容。Chrome 按地址连接，所以要靠连接开始时的握手中的网站名称来匹配。而躲在网站自己域名背后的跟踪器，比如 metrics.example.com，会在你的 Mac 查询域名时，从得到的回应中被识破，因为回应里写着它实际代表的跟踪器。

由你掌控。

在“广告与跟踪器”的设置（点按它的齿轮图标）中打开之前，它一直是关闭的；第一次打开时，macOS 会请你允许这个过滤器。除了内置列表，它还会使用它推荐的两个列表：HaGeZi Normal 和 OISD Big，两者合起来能拦下大部分广告，又很少导致网站出错。在它的“列表”的高级中，你可以改为自行选择：按主题，或者选择 HaGeZi、OISD、AdGuard 等的列表，也可以通过地址添加任何列表。你可以把它全部暂停一小时；你也可以针对某个网络关闭拦截，方便访问被列表拦截的网站。对于广告，你自己的规则说了算：永不阻止某个网站，或者始终阻止某个列表里没有的网站，可以针对所有应用或某一个应用；也可以完全放过某个应用。恶意软件和网络钓鱼列表无论如何都会照常拦截，在“连接”中允许某个应用，也不会放行它的广告。从 uBlock Origin 或 AdGuard 转过来？导入它的备份或你的规则，先看看会导入哪些内容，也能以同样的格式导出你的规则。

看看它拦下了什么。

广告与跟踪器有自己的部分：一天、一周、一个月或一年内拦截了多少，随时间的变化，以及被拦截最多的网站和应用。它的日志会在每个连接被判定时显示出来，并说明原因；每个列表也会显示它拦截了什么，所以很容易找出拦截过多的那个列表。弹出窗口会显示今天、本周或本月拦截了多少，“连接”会给每个被列入的服务器标上广告或恶意软件。

自动保持最新。

列表每周一重新生成；在打开期间，应用每周下载一次：每个人拿到的都是同一个签名文件，而且从不在热点上下载。如果某个列表突然少了一半的网站，就不会发布出去。应用内附带一份副本，所以离线也能使用。你添加的列表每周从其作者处获取，条件相同。匹配在你的 Mac 上进行，因此没有人会知道你的应用连接到了哪里。

网速测试

点按一下。
重新测量。

在弹出窗口中选择网络，再点按测试网速，NetworkMonitor 就会运行每台 Mac 都自带的网速测试，连接 Apple 最近的服务器。先测下载，再测上传，和网速测试一贯的做法一样。每次运行都重新测量，不使用任何缓存。

网速测试该有的数据，一样不少。

下载和上传速度，单位为 Mbps 或 MB/s，与菜单栏一致。空闲线路上的延迟和抖动，以及下载时和上传时的延迟：只要有别的东西在占用网络，通话就会卡顿，这个数字能说明原因。

告诉你是什么拖慢了速度。

NetworkMonitor 本来就知道哪些应用在使用你的网络。如果测试期间有应用在抢带宽，结果会直接点名，不用你去猜。

在热点上格外小心。

一次测试会消耗真实流量，通常为 50–500 MB。在按流量计费的连接上，它会先询问你，并显示上次在这里测试用了多少。

在菜单栏中查看进度。

测试运行时，读数会以青色显示测试数据；如果你选的颜色接近青色，就会改用其他颜色，所以绝不会被误认为是实时速度。测试结束后，结果会保留几秒钟。你也可以让应用列表保持可见：紧凑样式会在列表上方用两行显示测试。

和安装其他 Mac 应用一样：打开磁盘映像，把 NetworkMonitor 拖到应用程序文件夹中。

下载 NetworkMonitor.dmg 版本 1.28.2 · 14.5 MB · 通用版（Apple 芯片和 Intel）
  1. 打开 NetworkMonitor.dmg，把应用拖到应用程序文件夹中。
  2. 从“应用程序”中打开 NetworkMonitor。它使用 Apple Developer ID 签名并经过公证，因此 macOS 会直接打开它。
  3. 欢迎窗口会说明它经你同意后能做什么：网站名称，以及按名称识别 Wi‑Fi 网络。两者都是可选的。
  4. 在菜单栏中找到 ↓↑。

更新：从 1.15 起，NetworkMonitor 会主动提供每个新版本，点按它菜单中的检查更新…可立即检查。如果你用的是 1.14 或更早的版本，请下载这个版本并拖到旧版本上，选择替换，只需这一次。你的设置和历史记录都会保留。移除：右键点按菜单栏项目并选择卸载 NetworkMonitor…，它会先恢复它更改过的每项设置。
