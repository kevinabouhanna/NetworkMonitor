功能

NetworkMonitor 能做的一切，以及在哪里找到它们。

菜单栏读数

两行，始终可见：绿色的 ↓ 下载 在上，浅灰色的 ↑ 上传 在下，单位为 MB/s 或 Mbps（设置 › 速度显示单位）。Mbps 与宽带套餐的标称速度一致；MB/s 与流量总计一致。数据量始终以 MB 和 GB 显示，与流量套餐的计算方式相同。你可以在 设置 › 网速颜色 中选择其他颜色。

读数宽度固定，所以数字变化时，菜单栏中它旁边的项目不会跳来跳去。它每秒最多更新两次，使用电池和低电量模式时更新得更少（请参阅电池）。网速测试进行时，读数会以青色显示测试结果；如果你选的颜色接近青色，则改用另一组颜色，这样测试结果永远不会被误认为实时速度。

VoiceOver 用文字读出读数，先读下载：NetworkMonitor，下载 1.2 兆字节每秒，上传 30 千字节每秒；显示测试结果时读作 网速测试：下载 …（#497）。

  • 点按它可打开弹出窗口。
  • 右键点按（或按住 Control 键点按）它，可使用 测试网速、上一次的结果、全部阻止（#198）、暂停广告拦截（1 小时、直到明天，或每当连接此网络时），暂停期间则为 继续广告拦截（#600）、流量历史…（⌘Y）、连接…（⌘K）、广告与跟踪器…（⌘B）、网络…、设置…（⌘,）、关于 NetworkMonitor、检查更新…、卸载 NetworkMonitor… 和 退出。

改为显示在程序坞中

设置 › NetworkMonitor 显示在 决定应用显示在哪里（#69），选择后立即生效。

  • 菜单栏（默认）：上面的读数，只有打开窗口时才有程序坞图标。

  • 程序坞：菜单栏中不显示任何内容。它下面会出现 程序坞图标 选项（#523）：

    • 网速（程序坞的默认选项）：整个程序坞图标显示实时网速，下载在上、上传在下，画法与应用图标相同：同样的形状和光照，深色模式下接近黑色，浅色模式下接近白色，随 Mac 的外观切换。每个网速是应用图标中的箭头加上保留三位有效数字的数值（如 12.3），尽可能大，单位在数值下方，使用网速颜色（浅色模式下颜色会加深，以便看清）。与读数同步更新，每秒最多一次。
    • 应用图标：NetworkMonitor 自己的图标，不显示网速。

    点按图标会打开主窗口，显示上次所在的部分。它的菜单包含读数右键菜单中的所有内容（退出由程序坞自己提供）；选择网速时，最上面一行用文字写出网速，VoiceOver 就是在这里读出网速的。这个模式下没有弹出窗口：在热点上需要你确认的网速测试，会在 网络 页面中询问。

  • 两者：菜单栏中的读数，以及始终存在的程序坞图标。它下面也会出现 程序坞图标 选项，一开始为 应用图标，所以在你选择 网速 之前，程序坞图标一直是应用图标。程序坞和两者各自保留自己的选择。

没有“都不显示”这个选项：那样就没有办法回到应用了。

弹出窗口

  • 顶部的 今天 | 周 | 月 决定下面每个数字的统计周期：今天、本周或本月至今，涵盖所有网络，数据来自流量历史。弹出窗口会在你上次选择的统计周期上打开。
  • 四个按钮：数据、连接、已拦截 和 网络，每个都显示自己的数字。点按一个按钮，下面就会显示它的视图。这些颜色在整个应用中都一样：数据为蓝色，连接为青绿色，拦截为红色，热点为橙色。
  • 数据 列出用掉流量的 应用 或 网络，从多到少排列，每一项都有一个表示占比的条形。应用之间互相超过时，列表会实时重新排序；圆点表示此刻正在传输数据的应用。
    • 辅助进程归入所属应用：Chrome 的十几个辅助进程合并为一行 Google Chrome。
    • 命令显示在启动它们的应用下方。展开 iTerm2 或 VS Code，可以看到它启动的 node、git 或 curl，每个都有自己的数字。超过四个时会合并为 其他（n）。
    • 系统：macOS 自己的守护进程合并为底部的一行。好奇的话可以展开它。
  • 连接 按 公司、国家或地区 或 应用 对你的应用通信的对象分组。一个应用与一台服务器通信计为一次。公司或国家或地区可以展开为它的应用，应用可以展开为它的公司。
  • 已拦截 最上面是一栏，说明广告拦截现在是否在拦截，并提供 暂停：1 小时、直到明天 或 每当连接 此网络 时，与窗口中相同。暂停期间，这一栏会显示暂停到什么时候，并提供 继续；在此网络上关闭时，提供 在此处打开（#600）。下面列出 网站 或 应用，次数最多的在前。网站可以展开为尝试访问它的应用，应用可以展开为它尝试访问的网站。广告拦截关闭时，这里会提供 打开。
  • 网络 显示 Mac 正在使用的连接、一个 这是热点 开关（在每个网络上都有，因为有些手机无法被识别），以及网速测试：上一次的结果和 测试网速。
  • 每个视图底部的 打开… 会在主窗口中打开对应的部分，统计周期保持不变：打开流量历史（⌘Y）、打开“连接”（⌘K）、打开广告与跟踪器（⌘B）或 打开“网络”。齿轮图标旁边的 四个方块 也一样，齿轮图标 则打开“设置”。
  • 按钮下方的提示行 会说明需要注意的情况：
    • 你加入了热点，但 Mac 没有在使用它，ⓘ 中会说明如何切换；
    • 使用热点且打开了热点模式时，仍被下载的更新；
    • 打开“全部阻止”时，显示 已全部阻止 和 关闭；
    • 广告拦截已暂停，或在此网络上已关闭：点按它可前往“已拦截”，在那里 继续；
    • 按应用统计已暂停：如果无法启动 macOS 的 nettop，会以灰色显示。NetworkMonitor 会继续重试，总计不受影响，照常统计。

列表可显示六行，外加第七行的一部分，所以被截断的那一行说明下面还有更多。无论你选择哪种分组，列表的高度都保持不变。按 Esc 或点按其他地方即可关闭。

每个连接的总计

弹出窗口统计所有网络。网络 页面只统计你正在使用的网络：加入另一个 Wi-Fi 网络或热点后，它的总计会从零开始，所以你看到的就是这个连接用掉的流量。在新的地方打开热点，你就能确切知道它用了多少。如果要比较一段时间内各个网络的用量，请在弹出窗口的“数据”中选择 网络。

  • 断线后重新连接到同一个网络，会接着之前的数字继续统计。
  • 午夜时也会重置，即使你一直没有离开这个连接。
  • 重新启动后也会保留，在同一网络上重新打开应用会继续统计。
  • 立即重置（设置 › 弹出窗口中的累计值）会让当前网络的总计重新开始。
  • 统计开始于（设置 › 弹出窗口中的累计值）显示当前总计是从什么时候开始的。

不同网络通过路由器的硬件地址来区分，这不需要任何权限；网络则以它的 Wi-Fi 网络名称命名。只有在获得定位服务权限后，macOS 才会提供这个名称，应用会询问一次；如果你拒绝，网络会显示为类似 Wi-Fi · 3f2a 的名称。

每个网络的每个小时都会保存到流量历史中。

只统计互联网流量

投屏到 Apple TV、用时间机器备份到 NAS、从你自己的服务器播放 Plex：这些流量会经过你的 Wi-Fi，但不消耗互联网流量，所以永远不会被计入。只和你自己的网络通信的应用根本不会出现。请参阅准确性。

流量历史

按小时记录，可按应用和网络细分，保留多久由你决定。按日、周、月或年回顾；把每次访问某个网络看作一个连接时段；把所有内容缩小到一个应用、一个网络，或一次查看所有热点；导出为 CSV。请参阅流量历史。

连接

你的应用把数据发送给了哪些公司、来自哪些应用、在哪些国家或地区、发往哪些服务器：可以按公司、应用或国家或地区分组，点按以缩小范围，进行搜索，在时间线上逐小时查看，还可以在世界地图上以颜色深浅显示，地图会在你的应用此刻连接的地方闪动。所有内容都不会在线查询。你可以阻止某个公司、应用、国家或地区、网站或服务器，也可以让它在应用第一次连接时询问你；“流量”和“已阻止”旁边的 规则 会列出每一条规则以及它做了什么。请参阅连接。

广告与跟踪器

一个开关即可在所有应用中拦截广告、跟踪器和恶意软件网站。概览 显示所选时间段内拦截了什么，有图表，并按网站和应用列出，两者的用法与流量历史相同：指向或点按一根柱，选中或展开一行（#536）；日志 实时显示每个连接，以及过滤器对它作出的决定；规则 列出你自己的规则，与“连接”列出它的规则一样（#592）。列表在它的设置中。请参阅广告与跟踪器。

网速测试

点按一下，就会用 macOS 内置的工具重新测试一次：先测下载，再测上传，然后是延迟、抖动和负载下的延迟，单位为 Mbps 或 MB/s。如果有其他应用在争用线路，结果中会指出它。使用热点时，它会先询问你。请参阅网速测试。

热点模式

“网络”页面上的一个开关，就能在你使用移动热点时阻止应用更新，让连接进入低数据模式，并告诉你哪些应用无法阻止。请参阅热点模式。

主窗口

一个带边栏的窗口：流量历史、连接、广告与跟踪器 和 网络，顺序与弹出窗口相同，设置 固定在底部。点按边栏按钮，或选择 视图 › 隐藏边栏（⌃⌘S），即可隐藏边栏。有新版本时，设置 上方会出现一张卡片提供更新（更新）。

每个部分的工具栏以视图开头：流量历史和广告与跟踪器中是 列表、两者或图表，“连接”中是 列表、两者或地图（#524）；“两者”总是列表在左，图表或地图在右（#534）。工具栏中间是统计周期（日、周、月、年），然后是 ‹ 今天 ›、一个点按后展开为输入框的搜索按钮（⌘F），以及一个 齿轮图标。齿轮图标会在原处显示该部分自己的设置，并带有返回按钮。“网络”只关注当下，所以它只有齿轮图标。

设置

设置（⌘,）位于边栏底部，包含适用于整个应用的设置。每一行的含义在它旁边的 ⓘ 中说明，指针移到该行上时就会出现（#185、#189）。

  • 语言：跟随系统，或为应用单独选择
  • 登录时启动
  • NetworkMonitor 显示在：菜单栏、程序坞或两者；选择程序坞或两者时还有 程序坞图标：网速或应用图标
  • 速度显示单位：MB/s 或 Mbps
  • Wi-Fi 名称（打开之前显示）
  • 网速颜色（菜单栏读数和程序坞图标的颜色）：下载、上传、网速测试的颜色、使用默认颜色
  • 弹出窗口中的累计值：统计开始于、采样、立即重置
  • 自动检查更新，以及 立即检查
  • 各部分：每个部分的设置各有一行，与它的齿轮图标打开的页面相同

关于 NetworkMonitor 位于右键菜单和应用菜单中，是标准的“关于”窗口：版本、网站链接、新功能、源代码，以及许可证。

主窗口打开时，NetworkMonitor 会有程序坞图标和菜单，所以 ⌘W、⌘,、⌘Y、⌘K、⌘B 和 ⌘F 都能使用，⌘-Tab 也能找到它。关闭主窗口后，它又会回到只在菜单栏中运行的状态，除非你设置为显示在程序坞中或两者都显示。

如果主窗口在另一个应用后面打开着，点按菜单栏项目只会显示弹出窗口，主窗口仍留在后面。用 ⌘-Tab 或程序坞图标可以单独显示主窗口。

不打扰你

  • 没有程序坞图标，不出现在应用切换器中，没有需要管理的窗口。只在菜单栏中，除非你选择程序坞或两者。
  • 默认在登录时启动，只设置一次。在“设置”中关闭后，它就会保持关闭。
  • 退出后就保持退出。退出只会在本次登录期间结束它，不会关闭“登录时启动”；而关闭“登录时启动”也不会退出正在运行的应用。
  • 支持自动隐藏菜单栏：菜单栏隐藏时弹出窗口仍保持打开，主窗口仍保持在最前面。
